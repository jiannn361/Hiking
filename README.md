# 梅山登山地圖

將 `index.html`、`trails.js` 與整個 `route/` 資料夾放在同一個 HTTPS 網站。開啟首頁會顯示步道選單，選擇步道即可查看軌跡、地標與海拔圖。既有的 `?route=...`、`?s=...` 與 `view=1` 網址仍可使用。

## 加到 LINE 官方帳號

1. 先用手機開啟已部署的 HTTPS 首頁，確認可以選步道並顯示地圖。
2. 到 LINE 官方帳號管理後台的「圖文選單」，選取要放登山地圖的區塊。
3. 動作選「連結」，填入首頁網址，動作標籤可填「梅山步道地圖」。儲存後，從手機 LINE 聊天室點選該區塊測試。

只需要以圖文選單開啟地圖時，可直接使用網站網址。若要讓區塊直接開啟特定步道，可在該步道畫面按分享，複製該頁的連結。

GPS 需要使用者允許定位。如果 LINE 內無法定位，可以從右上角選單改用手機瀏覽器開啟。
